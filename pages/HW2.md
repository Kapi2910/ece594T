# Question 2.1
(a) Since $f(a) = 2a$ is a bijection, we can say that $|2\mathbb{Z}_{++}| = |\mathbb{Z}_{++}|$.
Hence, $2\mathbb{Z}_{++}$ is a countable set.

(b) Let $f: \mathbb{Z}_{++} \rightarrow \mathbb{Z}$ such that
$$
f(n) = \begin{cases}
\frac{n+1}{2}& \text{ if $n$ is odd}\\
\frac{-n}{2}& \text{ if $n$ is even}
\end{cases}
$$
Since $f$ is a bijection, we can say that $|\mathbb{Z}| = |\mathbb{Z}_{++}|$.
Hence, $\mathbb{Z}$ is a countable set.

(c) We know that $\mathbb{Q} = \set{\frac{p}{q}: p,q \in \mathbb{Z}}$
Let $f(\frac{p}{q} = (p,q)) \implies f: \mathbb{Q} \rightarrow \mathbb{Z} \times \mathbb{Z}_{++}$ 
Clearly $f$ is a bijection. Additionally, the set $\mathbb{Z} \times \mathbb{Z}_{++}$ is countable as it is the cartesian product of 2 countable sets. Thus, we can say that $|\mathbb{Q}| = |\mathbb{Z}_{++}|$
Hence, $\mathbb{Q}$ is a countable set
