# Convex Relaxation
	- For a given non-convex problem $f^\ast = \min f(x)$ with constraints $x \in \mathcal{S}$
	- we define a convex relaxation $\min g(x)$ with constraints $x \in \mathcal{T}$
		- $\mathcal{S} \subseteq \mathcal{T}$
		- $f(x) \geq g(x) \forall x \in \mathcal{S}$
	- The relaxed solution is a lower bound to the optimal solution.
